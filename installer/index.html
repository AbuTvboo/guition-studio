Guition Studio – Firmware installieren

Für das Guition ESP32-S3-4848S040 (4", 480 × 480). Direkt im Browser, ohne Zusatzsoftware.

Dieser Browser kann nicht per USB installieren.
Bitte Google Chrome oder Microsoft Edge am Computer verwenden (Windows, macOS oder Linux).
Firmware wird geladen …

So geht's

  1. Display mit einem USB-C-Datenkabel an diesen Computer anschließen.
  2. Auf „Display verbinden & installieren“ klicken und den Port wählen – meist USB-SERIAL CH340.
  3. Bei der ersten Installation „Gerät löschen“ bestätigen. Die Installation dauert etwa 1–2 Minuten.
  4. Danach im selben Fenster das WLAN auswählen und das Passwort eingeben.
  5. Auf „Zu Home Assistant hinzufügen“ klicken – oder in Home Assistant unter Einstellungen → Geräte & Dienste das entdeckte ESPHome-Gerät hinzufügen.
  6. In Home Assistant Guition Studio → Meine Displays öffnen und das Display verknüpfen. Fertig – jetzt Seiten gestalten.

Probleme?

  • Kein Port sichtbar: ein anderes Kabel probieren (viele Kabel laden nur). Unter Windows ggf. den CH340-Treiber installieren.
  • Verbindung schlägt fehl: BOOT-Taste auf der Rückseite gedrückt halten, kurz RESET drücken, BOOT loslassen und erneut verbinden.
  • Brave / Firefox / Safari / Handy: unterstützen USB-Installation nicht zuverlässig – bitte Chrome oder Edge am Computer nutzen.
